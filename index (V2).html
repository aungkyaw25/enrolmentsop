Process 1 · Timetable Setup

Locks the class before any folder or booking work begins
Sequencing rule. Timetable setup happens weeks before class day. Do not start the next step until the previous step has produced its output. The class folder must not be created until the timetable is locked.
⚠

Process 2 · Urgent Change Classes

Any change to date, trainer, or venue
Definition. Any change to a published class date, trainer, or venue triggers urgent change management. The change is not complete until every system and every audience has been updated.
✎

Process 3 · Student Enrolment

Opens at class creation, closes at T-24h
Hard cut-off. Student enrolment opens when the class is created in SMS / Hub System and closes at T-24h before class. The hard cut-off is required so pre-filled enrolment forms reflect the final list.
